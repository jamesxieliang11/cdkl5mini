### 病友社区帖子活动功能 ###
为希舞之家小程序新增希舞宝宝社区模块，支持发帖/评论/话题/分享（含截图+小程序码），包含 3 个新页面、1 个云函数、1 个分享组件，以及对应的 database.js 封装和首页入口。


## 功能概述

为希舞之家小程序新增「希舞宝宝社区」模块，包含以下核心功能：
- **发帖**: 希舞宝宝家庭可以发布帖子（文字+图片），支持匿名发帖
- **评论**: 对帖子进行评论
- **话题**: 管理员创建话题，帖子可关联话题，社区按话题聚合浏览
- **点赞**: 帖子和评论支持点赞
- **分享**: 支持微信原生转发 + 生成分享截图（内容摘要+小程序码）

## 数据库设计

### 新增 3 个集合

#### `community_posts` — 帖子集合
```javascript
{
  _id: String,
  user_id: String,              // 发帖用户 ID
  nick_name: String,            // 昵称（冗余存储，避免频繁联表）
  avatar_url: String,           // 头像（冗余）
  is_anonymous: Boolean,        // 是否匿名
  topic_id: String,             // 关联话题 ID（可选）
  content: String,              // 帖子内容（最多 2000 字）
  images: [{                    // 图片（最多 9 张）
    fileID: String,
    cloudPath: String
  }],
  like_count: Number,           // 点赞数
  comment_count: Number,        // 评论数
  view_count: Number,           // 浏览数
  is_pinned: Boolean,           // 是否置顶（管理员操作）
  status: String,               // 'active' | 'hidden' | 'deleted'
  created_at: Date,
  updated_at: Date
}
// 索引: user_id, topic_id, status, created_at(desc), is_pinned(desc)
```

#### `community_comments` — 评论集合
```javascript
{
  _id: String,
  post_id: String,              // 所属帖子 ID
  user_id: String,              // 评论用户 ID
  nick_name: String,            // 昵称（冗余）
  avatar_url: String,           // 头像（冗余）
  content: String,              // 评论内容（最多 500 字）
  reply_to_id: String,          // 回复的评论 ID（可选，用于楼中楼）
  reply_to_name: String,        // 回复的用户昵称
  like_count: Number,           // 点赞数
  status: String,               // 'active' | 'hidden' | 'deleted'
  created_at: Date
}
// 索引: post_id, user_id, created_at(desc)
```

#### `community_topics` — 话题集合
```javascript
{
  _id: String,
  title: String,                // 话题标题
  description: String,          // 话题描述
  icon: String,                 // 话题图标（emoji 或图片）
  post_count: Number,           // 帖子数
  is_hot: Boolean,              // 是否热门
  sort_order: Number,           // 排序权重
  status: String,               // 'active' | 'archived'
  created_by: String,           // 创建者 user_id（管理员）
  created_at: Date,
  updated_at: Date
}
// 索引: status, sort_order(desc), created_at(desc)
```

点赞记录复用已有的 `favorites` 集合（`item_type` 设为 `'post_like'` 或 `'comment_like'`），利用其 `user_id + item_id + item_type` 唯一索引防重复。

## 云函数设计

### 新增 `community` 云函数

路径: `base/cloudfunctions/community/index.js`

采用项目标准的 **action 分发模式**，包含以下 action：

| Action | 说明 | 权限 |
|--------|------|------|
| `createPost` | 发布帖子 | 所有用户 |
| `getPost` | 获取帖子详情 | 所有用户 |
| `listPosts` | 帖子列表（支持按话题筛选） | 所有用户 |
| `deletePost` | 删除帖子 | 作者本人 / 管理员 |
| `togglePinPost` | 置顶/取消置顶 | 管理员 |
| `createComment` | 发布评论 | 所有用户 |
| `listComments` | 评论列表 | 所有用户 |
| `deleteComment` | 删除评论 | 作者本人 / 管理员 |
| `toggleLike` | 点赞/取消点赞（帖子和评论） | 所有用户 |
| `createTopic` | 创建话题 | 管理员 |
| `listTopics` | 话题列表 | 所有用户 |
| `updateTopic` | 编辑话题 | 管理员 |
| `adminListPosts` | 管理员帖子审核列表 | 管理员 |
| `hidePost` | 隐藏帖子 | 管理员 |
| `getShareImage` | 生成分享截图数据（返回帖子摘要信息供前端绘制） | 所有用户 |

## 前端页面设计

### 新增 3 个页面

#### 1. `pages/community/index` — 希舞宝宝社区首页（帖子列表）

- **顶部**: 话题横向滚动栏（全部 / 话题1 / 话题2 / ...），点击筛选
- **发帖入口**: 右下角浮动按钮「发帖」
- **帖子列表**: 瀑布流卡片，每个卡片显示：
  - 用户头像+昵称（匿名则显示「匿名希舞宝宝」）
  - 帖子内容摘要（2行截断）
  - 图片预览（最多3张缩略图）
  - 话题标签
  - 底部：点赞数、评论数、发布时间
- **交互**: 上拉加载更多、下拉刷新
- **置顶帖**: 带「置顶」标签，排在最前

#### 2. `pages/community-post/index` — 发帖页

- 内容输入（textarea，最多 2000 字）
- 图片上传（最多 9 张，复用 feedback 的图片上传模式）
- 选择话题（可选，弹出话题选择器）
- 匿名发帖开关
- 发布按钮

#### 3. `pages/community-detail/index` — 帖子详情页

- **帖子内容区**: 完整内容、图片大图浏览、用户信息、发布时间
- **操作栏**: 点赞、评论、分享按钮
- **评论列表**: 按时间正序，支持回复（楼中楼一级）
- **底部评论输入框**: 固定底部，支持回复指定评论
- **分享功能**:
  - 点击分享按钮 → 弹出 ActionSheet：「转发给好友」/「生成分享海报」
  - 转发给好友：使用 `onShareAppMessage` 原生转发，带帖子摘要和路径
  - 生成分享海报：Canvas 2D 绘制截图（帖子标题、内容摘要、用户提供的小程序码图片、希舞之家品牌信息），保存到相册

### 新增 1 个组件

#### `components/share-poster/index` — 分享海报生成组件

- 使用 Canvas 2D API 绘制：
  - 顶部：希舞之家 logo + 「希舞宝宝社区」标题
  - 中间：帖子内容摘要（截取前 200 字）+ 帖子图片缩略图（如有）
  - 底部：小程序码图片（用户提供的静态图，存放在云存储或本地） + 「长按识别小程序码」提示
- 绘制完成后调用 `canvasToTempFilePath` 导出图片
- 支持保存到相册（`wx.saveImageToPhotosAlbum`）

## 小程序码方案说明

用户提供的小程序码图片将以静态资源方式使用：
1. 将小程序码图片上传到云存储（路径: `community-assets/qrcode.png`）
2. 分享海报组件绘制时从云存储下载此图片到临时路径，再绘制到 Canvas 上
3. 这样确保海报中的小程序码始终指向正式的小程序入口，用户扫码后打开小程序首页
