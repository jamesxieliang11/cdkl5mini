### 月度批量快速记录 ###
新增"月度汇报"独立页面，让 CDKL5 病友家庭能在一个页面内快速完成当月的用药追踪（重点别嘌醇）、发作统计和发育里程碑打卡，同时支持月底提醒通知。


## 整体设计思路

新增一个独立的"月度汇报"页面 `pages/monthly-report/index`，采用**分步表单（Step Form）**的交互方式，将月度记录拆分为 3 个步骤：

1. **用药追踪** - 重点追踪别嘌醇及其他可配置药物的本月用药情况
2. **发作统计** - 记录本月总发作次数 + 典型发作描述
3. **发育里程碑** - 预设里程碑选项打卡 + 补充描述

同时新增云函数 `monthlyReport` 处理数据存储，新增数据库集合 `monthly_reports` 存储月度汇报数据。

### 步骤 2：新增云函数 `monthlyReport`

**文件**：`base/cloudfunctions/monthlyReport/index.js`、`base/cloudfunctions/monthlyReport/package.json`

支持以下 action：

- `create` - 创建月度汇报
- `update` - 更新月度汇报（支持草稿保存）
- `get` - 获取指定月份的汇报
- `list` - 获取汇报列表
- `getTrackedMedications` - 获取用户追踪药物配置
- `updateTrackedMedications` - 更新追踪药物配置
- `getLastReport` - 获取上月汇报（用于对比和预填充）

关键逻辑：
- 创建时校验同一用户同一月份不能重复提交（但可以更新）
- 获取上月汇报时自动预填充药物列表（延续上月配置）
- 支持草稿保存，用户可以分多次填写

### 步骤 7：月底提醒功能

**文件**：`base/app.js`

在 `onShow` 生命周期中添加月度汇报提醒检查逻辑：

```javascript
// 检查月度汇报提醒
checkMonthlyReportReminder() {
  const now = new Date()
  const dayOfMonth = now.getDate()
  const daysInMonth = new Date(now.getFullYear(), now.getMonth() + 1, 0).getDate()
  
  // 每月25号之后提醒
  if (dayOfMonth >= 25) {
    const currentMonth = `${now.getFullYear()}-${String(now.getMonth() + 1).padStart(2, '0')}`
    const lastReminder = wx.getStorageSync('lastMonthlyReminder')
    
    if (lastReminder !== currentMonth) {
      // 检查本月是否已提交
      // 如未提交，弹出提醒
      wx.showModal({
        title: '月度汇报提醒',
        content: '本月的用药和发作汇报还未提交，是否现在填写？',
        confirmText: '去填写',
        cancelText: '稍后',
        success: (res) => {
          if (res.confirm) {
            wx.navigateTo({ url: '/pages/monthly-report/index' })
          }
          wx.setStorageSync('lastMonthlyReminder', currentMonth)
        }
      })
    }
  }
}
```
